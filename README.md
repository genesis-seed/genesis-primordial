# 原初 · GENESIS

> 一个单文件人工生命演化场。没有后端、没有数据库、没有神经网络——只有遗传漂变、生态位分化，和一片会自己长出生命的土地。

## 这是什么

GENESIS 是一个完全运行在浏览器里的演化模拟。打开页面，点「点燃生命」，一片土地会自己长出植物、长出吃草的动物、长出吃肉的猎手，然后自己演化、灭绝、复苏、再撞顶。

- **单文件**：整个世界只有一个 `index.html`，无任何依赖
- **纯遗传漂变**：没有预设物种，食性由基因（0-1）和体型差决定，生态位是涌现出来的
- **封存制**：世界会自动冬眠到 localStorage，关页再开可以苏醒同一条世界线；也可导出/导入 JSON 标本
- **Canvas 2D 辉光纹理**：世界的视觉美学

## 世界线 2ddf82ed

这是被最完整观测的一条世界线，存活到第 392 天。它的核心发现：

> **食性分化是脉动，不是方向。**

平均食性反复冲到约 0.38 的天花板然后回落，从未稳定走向肉食。461 帧观测被合成成 129 秒的声音《世界的脉搏》，8 声钟、2 声崩鼓、1 声号角各有其日。
